# Логбук docx-editor — закрытая работа

Журнал: что сделано, чем доказано, что при этом нашлось. Один файл — одна
закрытая фаза или партия. **Текст задним числом не редактируется** — это
журнал, а не документация; если решение изменилось, новая запись, а не
правка старой.

**Читать целиком не нужно.** Ищи по этой странице, по [указателю
находок](#указатель-находок-н-пункты) ниже или по [справочнику тем](../INDEX.md)
и открывай ровно один файл. В открытой работе логбук нужен, только когда
пункт `BUILD_PLAN.md` прямо сюда отсылает или нужно понять, ПОЧЕМУ было
принято решение.

## Живые прогоны: что они вскрыли

- **Первая живая приёмка** (Ф7, оба приёмочных корпуса) — 20/20 ColBERT,
  done 6 / failed 12 / rolled_back 2 / crashed 0; разбор дал пять находок
  Ф8. См. [phase-05-07-edit-cycle.md](phase-05-07-edit-cycle.md),
  [phase-08-10-acceptance-findings.md](phase-08-10-acceptance-findings.md).
- **Показ владельцу** (Ф9–Ф10) — вскрыл структуру документа (просмотрщик
  плоский там, где LibreOffice видит заголовки и списки) и обрыв потока
  `/edit` под облачным туннелем. См.
  [phase-08-10-acceptance-findings.md](phase-08-10-acceptance-findings.md).
- **Третий корпус `battery`** (Ф19-бис, 2026-07-28) — незнакомый документ,
  накопительно 60%, и один НОВЫЙ класс лжи (русское словоизменение при
  document-wide замене). См.
  [phase-17-21-routing.md](phase-17-21-routing.md).
- **Прогон за рулём** (2026-07-29) — архитектор сам провёл десять правок на
  своём документе через продуктовую ручку `/edit`: два новых класса лжи
  (подделка строки таблицы текстом, заголовок со слепленным текстом),
  структурные корпуса уронили совпадение с 79–84% до 7/10. Партия В1–В11 —
  прямое следствие этого прогона. См.
  [driving-run-2026-07-29.md](driving-run-2026-07-29.md).
