# Документация docx-editor

Заглавная страница. Отсюда — по ссылке к одному нужному файлу; читать всё
подряд не нужно и не надо (контекст сессии дороже полноты).

docx-editor — агент, который принимает `.docx` и правки обычным языком,
вносит их патчем к живым lxml-элементам исходного документа (никакой
пересборки «граф → новый файл») и возвращает файл плюс честный отчёт:
что сделано, что не вышло и почему. Как запустить (Python, зависимости,
модель, приёмочные корпуса) — [../CLAUDE.md](../CLAUDE.md), раздел
«Окружение»; отдельного `README.md` в корне проекта нет.

## Как устроен этот набор (и почему)

Три разных жанра, их нельзя смешивать в одном файле:

- **План** ([../BUILD_PLAN.md](../BUILD_PLAN.md)) — только *открытая* работа.
  Закрытый пункт оставляет в плане ничего (или одну строку-пометку, если на
  него есть открытая ссылка) и уезжает в логбук целиком.
- **Логбук** ([log/](log/README.md)) — журнал закрытого: что сделано, чем
  доказано, что нашлось. Один файл на фазу/партию, задним числом не
  правится. Открывается по ссылке поштучно, не целиком. Здесь же —
  [указатель находок Н1–Н70](log/README.md#указатель-находок-н-пункты).
- **Справочная** ([CONVENTIONS.md](CONVENTIONS.md)) — действующие правила.
  Это *настоящее время*: тут текст как раз правится, когда меняется
  реальность (новая операция, новый маршрут).

Переоткрытие пункта (регресс) — движение обратно: из логбука в план, с
пометкой «переоткрыто ДАТА: причина» (см. CLAUDE.md, «Находки по ходу»).

## Состояние

Мерило приёмки — три корпуса (два плоских, один структурный), см.
CONVENTIONS.md «Мерило». Маршрутизация правок по классу (`rule`/`unify`/
локальная/`compose`) реализована целиком, но статус маршрута `unify` **не
решён** — измерен трижды и ни разу не окупился по правилу проекта «прирост
меньше трёх ничего не доказывает» (см. [BUILD_PLAN.md](../BUILD_PLAN.md) и
[log/phase-17-21-routing.md](log/phase-17-21-routing.md)). Последний живой
прогон — архитектор за рулём на своём документе 2026-07-29 — вскрыл новый
класс лжи (код проверял факт изменения, не его класс) и породил партию
В1–В11, разбор которой ещё не закрыт целиком: [log/driving-run-2026-07-29.md](log/driving-run-2026-07-29.md).
